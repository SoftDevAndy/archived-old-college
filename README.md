# Archived College Projects

A collection of college programming projects by SoftDevAndy.

## Projects

- [distributedsystems](distributedsystems/) - A Java client and service for cracking Vigenere ciphers using worker threads and quadgram scoring.
- [dungeongame](dungeongame/) - A Java dungeon game built to practise object-oriented design and game development.
- [escapethemaze](escapethemaze/) - A Java maze game with inventory, combat, monster pathfinding, and fuzzy logic experiments.
- [googlecardboardblackjack](googlecardboardblackjack/) - A Unity blackjack game for Google Cardboard controlled with head gestures.
- [wordcloud](wordcloud/) - A Java application that generates word clouds from text files or URLs through a GUI or command line.
- [datastructures](datastructures/) - Java exercises in file parsing, code-book generation, text encoding, serialization, and one-time pads.
- [anagramsolver](anagramsolver/) - A Python Countdown letters solver that finds the longest valid words from nine letters.
- [nodejsapi](nodejsapi/) - A Node.js API and browser interface for Galway tourism and recreation data stored in PouchDB.
